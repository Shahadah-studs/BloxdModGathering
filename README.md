## About

**BloxdModGathering** is a community-driven, open-source repository that serves as a centralized hub for Bloxd.io customizations. This project was created to help players and developers:

- 🔍 **Discover** new mods and code snippets
- 📚 **Learn** from well-documented examples
- 🤝 **Contribute** their own creations
- 🎯 **Organize** game enhancements in one place

Bloxd.io is a fast-paced, voxel-based online game, and this repository empowers the community to extend its capabilities through mods and custom code.

## What's Inside

### 📦 Mod Collection
Pre-built and tested mods that add new features, gameplay mechanics, and visual enhancements to Bloxd.io games.

### 💻 World Code Snippets
Reusable JavaScript code for Bloxd.io world scripting, including utility functions, game mechanics, and creative implementations.

**Example:** The `Super Pickaxe` mod in `worldcodeZ/superpickaxeworldcode.js` demonstrates advanced block manipulation with visual particle effects.

### 📖 Documentation
Clear, step-by-step guides for implementing and customizing mods and code snippets in your Bloxd.io worlds.

## Repository Structure

```
BloxdModGathering/
├── README.md              # This file
├── index.html             # GitHub Pages portal
├── mods/                  # Pre-built mod collection
│   └── [mod folders]

    ├── superpickaxeworldcode.js
    └── [other scripts]
```

**Key Directories:**

| Directory | Purpose |
|-----------|---------|
| `mods/` | Contains ready-to-use mods with all dependencies |
| `worldcodeZ/` | JavaScript world code snippets and utilities |

## Getting Started

### 1. Browse the Repository
- Explore the `mods/` folder for complete mod implementations
- Check `worldcodeZ/` for JavaScript code examples
- Visit the [GitHub Pages site](https://shahadah-studs.github.io/BloxdModGathering/) for an interactive overview

### 2. Install a Mod
1. Navigate to the desired mod folder
2. Read the included documentation (typically in a `README.md`)
3. Copy the files to your Bloxd.io world
4. Follow setup instructions (usually involves pasting world code)

### 3. Implement Code Snippets
1. Open `worldcodeZ/` and find a code snippet that interests you
2. Review the code comments and documentation
3. Copy the relevant code into your Bloxd.io world script editor
4. Customize variables and behavior as needed

### 4. Create Your Own
Feel free to create new mods or code snippets! See the [Contributing](#contributing) section below.

## Technologies Used

### Primary Stack
- **JavaScript** (74.3%) – Core language for all mods and world code
- **HTML** (25.7%) – GitHub Pages portal and documentation

### Bloxd.io API
- `api.getHeldItem()` – Retrieve player's held item
- `api.getBlock()` – Read block information
- `api.setBlock()` – Modify blocks
- `api.createItemDrop()` – Spawn item drops
- `api.playParticleEffect()` – Render visual effects

## Contributing

We welcome contributions from developers of all skill levels! Here's how to contribute:

### Adding a New Mod or Code Snippet

1. **Fork** this repository
2. **Create a feature branch** (`git checkout -b feature/my-awesome-mod`)
3. **Add your mod or code** to the appropriate directory
4. **Write documentation** (include comments, a README, and usage instructions)
5. **Commit and push** your changes
6. **Open a Pull Request** with a description of your contribution

### Contribution Guidelines

- ✅ Ensure all code is **tested and working**
- ✅ Include **clear comments** explaining functionality
- ✅ Add a **README.md** or documentation file for your contribution
- ✅ Follow existing code style and naming conventions
- ✅ Test your code in Bloxd.io before submitting
- ❌ Avoid submitting broken or untested code
